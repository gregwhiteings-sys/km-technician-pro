C0202 — Tray 1 Lift-Up Failure

Error Type: Paper Feed / Tray Mechanism

Causes: Obstruction, wrong paper size, lift motor/sensor failure, mechanical bind, loose connector, failed lift clutch.

Repair: Pull tray → clear obstructions → check clutch/motor → reseat connectors → clear error → test.

C0601 — Fuser Warm-Up Failure

Error Type: Fuser / Thermal System

Severity: 🔴 CRITICAL

Causes: Fuser not seated, dirty thermistor, blown thermofuse, burnt heater element, low voltage, fuser motor failure.

⚠️ Safety: Let cool 15+ minutes before service. Do NOT repeatedly reset — fire risk.

C2550 — Black Developer Density Error

Error Type: Imaging / Developer Unit

Causes: Dirty ID sensor, developer expired, wrong toner ratio, unit not seated, transfer belt contamination.

Repair: Clean sensor → replace developer → run Auto Density Adjust → inspect belt → test.

📄 Jam Codes & Paper Path

General Jam Clearing Procedure

  1. Locate indicator → 2. Open correct door → 3. Remove paper WITH direction of travel → 4. Check for scraps → 5. Clean sensors/rollers/transfer → 6. Verify paper size → 7. Close & test.
⚠️ NEVER pull paper backward — damages sensors, transfer belt, and leaves fragments!

Common Jam Locations

  • Tray Feed Area: Feed roller, separation pad, paper size sensor, lift mechanism
  • Transport Path: Guide plates, registration roller timing, paper dust on sensors
  • Drum/Transfer Area: ⚠️ Remove carefully — do NOT scratch drum surface
  • Fuser/Exit Area: ⚠️ HOT — Let cool first. Check exit sensor flags, separation fingers
  • Finisher/Output: Exit gate, staple obstruction, tray alignment, stacker motor

🔍 Step-by-Step Troubleshooting

Standard Service Procedure

  1. Identify: Exact model & serial number
  2. Error: Record full error code + sub-code + when it occurs
  3. Symptom: Copy? Print? Scan? Fax? Warm-up? Specific tray?
  4. Obvious: Paper, toner, doors, trays, power, environment
  5. Power Cycle: OFF → Wait 60 sec → ON → Does error return?
  6. Connectors: Reseat ALL harnesses (power OFF first)
  7. Sensors/Components: Clean sensors, belts, coronas → check clutch/motor operation
  8. Diagnostics: Service Mode → Input/Output checks → component tests
  9. Repair/Replace: Replace confirmed failed part
  10. Reset: Clear error history → reset counters → calibrate
  11. Verify: Test thoroughly → full function check → quality inspection
  12. Document: Record meter reading, work performed, parts used

🧰 Maintenance Schedule

Preventive Maintenance Intervals

  • Every 50K copies / Monthly: Clean feed rollers, separation pads, paper path sensors, corona wire/grid, scanner glass, white reference plate
  • Every 100K copies: Replace feed rollers & separation pads, inspect transfer belt, lubricate lift rails
  • Every 200K copies: Replace transfer belt & roller assembly, fuser PM, scanner rails, clutch timing, motor gears
  • Every 500K copies: Full PM Kit — developer, drum, belt, fuser, rollers, clutches, motors

* Actual intervals vary by model, volume, paper quality, and environment. Always verify with your specific service manual.

🔑 Service Mode Access

⚠️ Changes critical machine operating parameters — record original values before making any adjustments!

Access Sequence — bizhub & Accurio Series

Utility/Counter → Stop → 0 → 0 → Stop → 0 → 1

Default Password: Usually 00000000 or 12345678

Common Functions

  • System 1: Input check (sensor readings, temp, voltage), Output check (component test), Counters, Firmware
  • System 2: Error history, clear errors, machine settings, network config, date/time
  • Image Adjustment: Auto density calibration, colour registration, gradation, scanner calibration
  • Counter/Life: Consumable counters reset — Drum, Developer, Fuser, Transfer Belt, Feed Rollers

🖼️ Print Quality Guide

  • Faded / Light Print: Toner/dev expired → dirty ID sensor → worn transfer belt/roller → belt contamination → clutch not engaging → wrong paper type → damp paper
  • Streaks / Lines: Drum scratched → cleaning blade → fuser roller mark → laser scanner glass dusty → transfer belt scratch → corona dirty
  • Ghosting / Repeat Marks: Fuser temperature → drum cleaning failure → belt blade → damp paper → motor speed variation → measure spacing to identify part
  • Toner Not Fusing / Rubs Off: Thermistor displaced → wrong paper weight setting → fuser motor → pressure spring → counter expired → low mains voltage
